# Hima Vamsi Expense Tracker

A Personal Finance Management Desktop Application built using **Python, Tkinter, and SQLite**.

## Project Overview
Hima Vamsi Expense Tracker is a desktop application designed to manage personal income and expenses. It helps users record transactions and monitor their financial balance.

## Features
- Dashboard with Total Balance
- Income and Expense Management
- Add New Transactions
- Transaction History
- Search Transactions
- Filter by Transaction Type
- Filter by Category
- SQLite Database Storage
- Windows Executable (EXE) Version

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python Hima_Vamsi_Expense_Tracker_V2.py
```
